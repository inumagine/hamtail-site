2.0で追加・強化した機能

1.0の使い方を残したまま、普段のコピー作業とコマンド実行をより長く使える形へ拡張しています。

NEW

コピータブを自由に追加

コピー1〜3はそのまま残し、＋ボタンでコピー4、コピー5…を追加できます。追加したページは次回起動時も復元されます。

NEW

追加タブだけ削除

−ボタンでコピー4以降だけ削除できます。標準のコピー1〜3は削除されません。

NEW

クリップボード履歴

WindowsのWin+V履歴を起動時に取り込み、COPYぺ上から再コピーできます。起動後のコピーも自動で記録します。

NEW

履歴をずっと残す

表示中の履歴を保存すると、既存TXTへ重複を避けながらマージします。Windows側から消えた履歴もCOPYぺ側に蓄積できます。

NEW

履歴クリア

履歴画面とWindowsのWin+V履歴をまとめてクリアできます。保存済みの履歴TXTは削除しません。

NEW

PowerShell 7でコマンド実行

複数行コマンドや .ps1 スクリプトをPowerShell 7で実行できます。Git操作やビルドコマンドの登録にも使えます。

NEW

コピー見出しを変更

「コピー内容」の列見出しを用途に合わせて変更できます。メール、URL、開発用など、ページごとの整理がしやすくなりました。

NEW

LAN共有

同じLAN内のPC間で共有用のコピー内容を扱える機能を追加。既存のローカルコピー機能とは分けて利用できます。

使い方のイメージ

普段使い

  • 定型文をコピー1〜3へ登録
  • 用途が増えたら＋でページ追加
  • コピー履歴から過去内容を再利用
  • 必要な履歴だけ長期保存

開発・管理作業

  • よく使うGitコマンドをCMDへ登録
  • PowerShellスクリプトをワンクリック実行
  • Explorer OPENで作業フォルダへ移動
  • LAN共有で別PCとも内容を受け渡し
