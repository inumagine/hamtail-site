2.0で追加・強化した機能

1.0の使い方を残したまま、普段のコピー作業、コマンド実行、端末間の受け渡しまで1本で扱えるように拡張しています。

NEW

コピータブを自由に追加

コピー1〜3はそのまま残し、＋ボタンでコピー4、コピー5…を追加できます。追加したページは次回起動時も復元されます。

NEW

追加タブだけ削除

−ボタンでコピー4以降だけ削除できます。標準のコピー1〜3は削除されません。

NEW

クリップボード履歴

WindowsのWin+V履歴を起動時に取り込み、COPYぺ上から再コピーできます。起動後のコピーも自動で記録します。

NEW

履歴をずっと残す

表示中の履歴を保存すると、既存TXTへ重複を避けながらマージします。Windows側から消えた履歴もCOPYぺ側に蓄積できます。

NEW

履歴クリア

履歴画面とWindowsのWin+V履歴をまとめてクリアできます。保存済みの履歴TXTは削除しません。

NEW

PowerShell 7でコマンド実行

複数行コマンドや .ps1 スクリプトをPowerShell 7で実行できます。Git操作やビルドコマンドの登録にも使えます。

NEW

コピー見出しを変更

「コピー内容」の列見出しを用途に合わせて変更できます。メール、URL、開発用など、ページごとの整理がしやすくなりました。

NEW

PC間LAN同期

親PCと子PCを6桁PINで接続し、LAN共有タブの10件を同じLAN内で同期できます。子PCは親PCを自動検索します。

NEW

スマホ・タブレット連携

スマホ側にアプリを入れず、ブラウザから共有テキストを利用できます。QRコードで接続先を簡単に開けます。

NEW

Webファイル共有

スマホや別PCから親PCへファイルをアップロードし、共有フォルダーのファイルをブラウザからダウンロードできます。

LAN共有の使い方

Windows PC同士は専用LAN同期、スマホやタブレットはWebブラウザで参加できます。

1. 親PCを設定

「LAN同期」→「このPCを親にする」を選び、6桁PINを設定します。

2. 子PCを接続

別のWindows PCで「このPCを子にする」を選び、同じPINを入力します。親PCは自動検索されます。

3. Web共有をON

スマホも使う場合は親PCで「Web共有を使用する」をONにします。

4. QRから接続

「スマホ接続QR」をスマホで読み取り、ブラウザで6桁PINを入力します。

スマホ・Web共有でできること

共有テキスト

  • LAN共有の10件をスマホで表示
  • スマホのCOPYボタンでクリップボードへコピー
  • スマホ側で内容を編集
  • 「親へ反映」で親PCへ送信
  • 親PCからWindows子PCへも同期

共有ファイル

  • スマホや別PCからファイルをアップロード
  • 親PCの共有フォルダーへ保存
  • ブラウザからファイル一覧を確認
  • スマホや別PCへダウンロード
  • 親PCから「共有フォルダーを開く」で直接確認

共有フォルダー：親PCの「ドキュメント\COPYぺ共有」　／　Web共有ポート：46180

LAN共有について

同じLAN内で利用

LAN共有とWeb共有は、家庭内・社内など信頼できるネットワークでの利用を想定しています。クラウドへアップロードする機能ではありません。

6桁PINで接続

PC間同期とWeb共有は親PCに設定した6桁PINを使用します。QRコードにはURLのみを含み、PINは含みません。

VPNでも利用可能

VPN側で端末間通信と必要ポートが通る構成であれば利用できます。Windowsファイアウォールの許可が必要になる場合があります。
